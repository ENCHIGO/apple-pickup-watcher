# Apple Pickup Watcher 自动结账助手

这是 Apple Pickup Watcher 的本地 Chrome 扩展，只在 Apple 官方在线商店页面工作。
自动结账当前仅启用中国大陆站；其他地区仍会提醒并打开购物袋。

它会在监控命中后：

1. 打开监控项对应的精确 SKU；
2. 自动选择不折抵、不加 AppleCare（页面提供这些选项时）；
3. 加入购物袋并进入结账；
4. 只选择监控项指定的直营店，找不到目标门店就停住；
5. 到付款、订单复核或最终下单阶段立即停止。

它不会自动添加配件，每次只加入 1 台命中的手机。它也不会读取或保存 Apple 账户密码、验证码和支付信息，更不会点击“立即下单”、
“提交订单”、“支付订单”、“Place order”一类最终按钮。任务 30 分钟后自动失效。
每个任务只属于触发它的浏览器标签页，不会被同时打开的其他 Apple 页面接管。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`；
2. 打开右上角“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择本目录；
5. 回到 Apple Pickup Watcher，打开“自动进入付款页”。

预购开始前应保持 Apple 官网已登录，并确认账号里的联系方式可用。Apple 可能随时
调整结账页面；扩展遇到不认识的页面会停住，不会猜测点击。
